# Wanderwise 🌍✈️

Wanderwise is your smart travel companion — a web application inspired by TripAdvisor that helps users explore countries, discover top attractions, restaurants, and book tour packages with ease. Users can also favorite destinations and build their dream travel wishlist.

## 🌟 Features

- Browse countries and view their popular destinations, restaurants, and tour packages.
- Add favorite places to a personal wishlist.
- Book travel packages directly through the platform.
- Organized and intuitive UI with separate static assets.

## 🛠️ Tech Stack

- **Database**: SQL
- **Frontend**: HTML, CSS, JavaScript
- **Static Assets**: Stored in the `static/` folder (CSS, JS, and images)
